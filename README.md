# 🏛️ Kalam Mowarekhin | كلام مؤرخين

> **The Official E-Learning Platform for Mr. Neshat El-Husseini**  
> A high-performance, responsive e-learning web application designed for Egyptian high school students studying History, Geography, and Geology.

---

## 🚀 Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Library:** [React 19](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Font:** [Google Tajawal](https://fonts.google.com/specimen/Tajawal) (RTL Arabic Support)
- **UI Notifications:** [React Hot Toast](https://react-hot-toast.com/)

---

## ✨ Features Implemented

- **Responsive RTL Design:** Optimized for seamless Arabic user experience across desktop and mobile devices.
- **Hero & Landing Section:** Dynamic historical visual composition showcasing Mr. Neshat with historical figures.
- **Custom Authentication Pages:** Streamlined, pixel-perfect Login (`/login`) and Registration (`/register`) user flows.
- **Dynamic Layout Management:** Smart conditional layout rendering to hide/show navigation components seamlessly on auth pages.
- **Parent Dashboard Entry:** Quick access and tracking call-outs for parent monitoring.

### Prerequisites

Ensure you have **Node.js 18.x** or higher installed.

1. **Clone the repository:**
