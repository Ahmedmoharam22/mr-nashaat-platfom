## 📌 Problem & Solution (Overview)

- **The Problem:** High school students need a fast, distraction-free platform to access organized history video lessons, download attached study guides (PDFs), and track their progress without dealing with slow or cluttered interfaces.
- **The Solution:** A modern, mobile-responsive **RTL-first EdTech LMS** featuring an custom video player with multi-speed controls (`0.5x` to `2x`), robust course creation for teachers, and instant live deployment.

## ✨ Key Features At A Glance

### 👨‍🏫 Teacher Management

- **Course & Content Control:** Effortlessly create courses, assign grade levels in Arabic, set prices, and upload structured lessons.
- **Smart Video Embeds:** Supports YouTube, Vimeo, and direct video sources with zero setup friction.
- **PDF Attachments:** Quick upload and attachment of revision sheets and lesson notes.

### 🎬 Student Experience

- **Cinematic Custom Video Player:** Features speed playback controls (`0.5x`, `1x`, `1.25x`, `1.5x`, `2x`), 10-second skip buttons, and keyboard shortcuts.
- **RTL First & Native Arabic UI:** Styled with Google's `Tajawal` font for an exceptional native Egyptian UI/UX.
- **Responsive Layout:** Pixel-perfect rendering across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS
- **State Management:** Zustand
- **Database & Auth:** MongoDB, Mongoose, NextAuth.js / Auth.js
- **UI Components:** Lucide Icons, React Hot Toast, Custom Video Modals
